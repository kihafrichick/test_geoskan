# getfield16 — Извлечение 16-битного поля из hex-строки

## Описание
Консольная утилита для извлечения 16-битного поля из бинарного буфера, заданного в виде hex-строки. Программа считывает hex-строку и номер стартового бита, извлекает 16 бит и выводит результат в hex-формате.

### Ограничения и правила
- Максимальный размер входной hex-строки: 32 символа (128 бит).
- Минимальный размер входной hex-строки: 4 символа (16 бит).
- Нумерация битов начинается с нуля.
- Старший бит имеет меньший номер (big-endian).

## Установка и запуск
- Откройте терминал (командную строку), перейдите в папку с проектом и выполните команду для установки необходимых библиотек:
    pip install -r requirements.txt
- Для запуска утилиты в интерактивном режиме выполните:
    python getfield16.py - запуск скрипта
- Утилита покрыта unit-тестами. Для запуска всех тестов с подробным выводом результатов используйте команду:
    pytest test_getfield16.py -v - запуск тестов
